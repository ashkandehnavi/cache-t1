## پیش‌نیاز

* زبان‌های مجاز: **C#**، **Node.js**، **Python**، **Java**، **Go**، **Rust**
* نسخه‌های پیشنهادی: `.NET 6`، `Node 20+`، `Python 3.11+`، `Java 17+`، `Go 1.21+`، `Rust 1.70+`
* سیستم‌عامل: آزاد (Windows / Linux / macOS)
* آشنایی با:

  * مفاهیم پایه برنامه‌نویسی
  * ورودی/خروجی در کنسول
  * مدیریت خطا (`try/catch`، `try/except`، `Result`)

---

## شرح مسئله

برنامه‌ای بنویسید که:

1. دو عدد از کاربر دریافت کند (به صورت ورودی کنسولی).
2. عملیات **جمع** را روی آن‌ها انجام دهد.
3. نتیجه را با قالب‌بندی استاندارد در خروجی نمایش دهد.
4. در صورت ورود داده‌ی نامعتبر (مثل متن به‌جای عدد) پیام خطای مناسب چاپ کند.

**هدف:** تمرین مفاهیم پایه‌ای ورودی/خروجی، کنترل خطا و ساختار کدنویسی تمیز در زبان‌های مختلف.

---

## قوانین و محدودیت‌ها

* تنها عملیات مجاز: **جمع**
* ورودی باید از طریق ورودی استاندارد خوانده شود (`Console.ReadLine()` / `input()` / `readline()` و مشابه).
* مدیریت استثناها الزامی است (نباید برنامه کرش کند).
* استفاده از کتابخانه‌های خارجی ممنوع است مگر بخشی از کتابخانه استاندارد زبان باشد.
* کد باید خوانا و دارای توضیحات کافی باشد.

## ورودی/خروجی و مثال

**ورودی نمونه:**

```
Enter first number: 7
Enter second number: 5
```

**خروجی نمونه:**

```
Result: 12
```

**ورودی نامعتبر:**

```
Enter first number: abc
```

**خروجی:**

```
Invalid input! Please enter numeric values only.
```

## نحوه اجرا و تست

### 1) کلون پروژه

```bash
git clone https://github.com/dotin-challenge/cache-t1.git
cd cache-t1
```

### 2) اجرای برنامه (بسته به زبان)

#### ▶ C#

```bash
dotnet build
dotnet run
```

#### ▶ Node.js

```bash
node solutions/<username>/index.js
```

#### ▶ Python

```bash
python solutions/<username>/main.py
```

#### ▶ Java

```bash
javac solutions/<username>/Main.java
java solutions.<username>.Main
```

#### ▶ Go

```bash
go run solutions/<username>/main.go
```

#### ▶ Rust

```bash
cargo run --bin <username>
```

### 3) اجرای تست‌ها (اختیاری)

اگر فایل تست وجود دارد:

```bash
dotnet test
# یا
npm test
# یا
pytest
```

## نحوه ارسال (PR)

1. ریپو را **Fork** کنید.
2. یک برنچ جدید بسازید:

   ```bash
   git checkout -b solution/<username>
   ```
3. کد خود را در مسیر زیر قرار دهید (بر اساس زبان انتخابی):

   ```
   solutions/<language>/<username>/
     ├─ فایل(های) کد منبع
     └─ README.md (اختیاری)
   ```
4. مثال:

   ```
   solutions/C#/user-1/
     ├─ Program.cs
     └─ README.md
   ```
5. یک Pull Request با عنوان زیر باز کنید:

   ```
   [Solution] ماشین حساب تک‌عملگر - <username>
   ```
